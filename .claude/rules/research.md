# 조사와 근거 규칙

1. 대회 주최 측 공식 결과를 먼저 확인하고, 거래소 공식 인터뷰·우승자 원문·검증 가능한 인터뷰를 보완한다. 검색 요약이나 광고성 재게시물만으로 우승 및 전략을 확정하지 않는다.
2. 대회명, 개최일, 거래소, 현물/선물, 개인/팀, 순위 기준(수익률/절대손익/거래량), 참가 요건, 기간, 우승자명, 원문 URL, 게시일, 열람일, 근거 강도를 기록한다. 서로 다른 부문 우승을 구분한다.
3. 최소 5개 검증 사례를 목표로 하되 사례를 채우려고 근거를 낮추지 않는다. 공개 정보가 없으면 명시한다. 익명 팀장의 발언을 팀 전체의 검증된 매매법으로 취급하지 않는다.
4. 공개된 진입·청산·포지션 크기·손절·레버리지·시장 조건을 표로 정리한다. 미공개 항목은 '미공개'로 표시한다. 공개 발언, 연구자의 해석, 구현을 위한 추가 가정을 분리한다.
5. 공통 원칙별로 이를 지지하는 독립 사례 수와 전체 조사 사례 수를 함께 표시한다. 같은 인터뷰의 복제 기사는 하나의 근거다. 규칙이 비슷한 이유와 다른 적용 조건도 설명한다.
6. 대회 성과와 장기 기대수익을 구분한다. 짧은 기간, 고레버리지, 팀 집계, 보너스, 입출금, 수익률 분모 및 생존자 편향을 검토한다. 우승자가 실제 전략 전체를 공개했다고 가정하지 않는다.
7. 전략마다 '출처 → 원칙 → 정량 가설 → 코드 규칙 → 검증 지표' 연결표를 작성한다. 유명인의 이름으로 자체 전략을 포장하지 않는다.
8. 거래소 명세와 비용은 해당 상품의 최신 공식 문서로 확인한다. 링크, 적용 계정 등급, 확인 시각을 남긴다. 확인 불가 시 수치를 가정으로 표시하고 민감도 분석을 한다.
