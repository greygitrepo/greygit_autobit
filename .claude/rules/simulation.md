# 실전 모의거래와 평가 규칙

## 데이터와 체결
- 과거 백테스트, 과거 이벤트 재생, 실시간 공개 데이터 기반 paper trading, 거래소 testnet을 구분한다. testnet 유동성과 체결이 실거래를 대변한다고 가정하지 않는다.
- 전략은 주문 생성 시점까지 도착한 정보만 본다. 캔들 종료 신호는 다음 체결 가능 이벤트부터 적용한다. 데이터의 거래소 시각과 로컬 수신 시각을 모두 기록한다.
- 시장가는 호가 스프레드·수량별 호가 깊이·지연 후 가격을 반영한다. 지정가는 가격 접촉만으로 체결시키지 않고 대기열·거래 발생·부분 체결을 보수적으로 모델링한다. 호가 자료가 없으면 정밀 체결 모형의 한계를 밝힌다.
- maker/taker 수수료, 펀딩 시각·방향·금액, 스프레드, 슬리피지, tick/step size, 최소 주문금액, 증거금, mark price 기반 청산과 유지증거금을 반영한다. 상품별 공식을 공식 문서에서 확인한다.
- WebSocket 단절·재접속·누락·중복·순서 역전·REST 호출 제한·429 응답·타임아웃·응답 지연을 다룬다. 주문 식별자와 중복 방지, 주문 상태 재조회, 시계 오차 및 stale 데이터 거래 중지를 구현한다.
- 데이터 단절 시 새 진입을 중지한다. 모의거래에서도 주문 상태를 모르면서 재주문하지 않는다. 재시작 시 포지션·미체결·잔고 상태를 복원하고 대조한다.

## 검증과 경합
- train/validation/test를 시간순으로 분리하고 구간 경계를 기록한다. 중첩 라벨/포지션의 누수는 purge/embargo 등 필요한 조치로 막는다. 최종 test는 튜닝에 재사용하지 않는다.
- 공통 데이터·자본·상품·기간·위험 제한·비용·체결 엔진으로 경합한다. 테스트 구간과 순위 기준은 결과를 보기 전에 동결한다. 실험 횟수와 실패 결과를 모두 등록한다.
- walk-forward, 시장 국면별 결과, 비용/지연 악화 스트레스, 파라미터 안정성, 단순 기준 전략과 현금 보유 비교를 수행한다. 기준 전략에도 동일한 비용과 위험 제약을 적용한다.
- 비용 차감 수익률, 최대 낙폭, Sharpe/Sortino의 산식·주기, 거래 수, 승률, 손익비, profit factor, turnover, 노출, 청산/거절/부분 체결 수, 비용 구성, 실시간 관측 시간 및 데이터 가동률을 보고한다.
- 위험 제한 위반·회계 오류·누수는 순위에서 제외한다. 나머지는 검증 구간의 비용 차감 수익률/최대 낙폭을 우선 비교한다. 최대 낙폭이 0이거나 거래 표본이 적으면 이 비율로 우승을 확정하지 않는다. 단기간 연율화 지표로 장기 성과를 주장하지 않는다.
- 거래 수와 표본 기간이 부족하면 탐색적 결과로 표시한다. 주말의 2~3일 모의 결과는 장기 수익성의 증거가 아니다. 승자가 없다는 결론을 허용한다.

## 필요한 테스트
수수료·펀딩·롱/숏 손익·부분 체결·주문 취소·반복 메시지·재시작 복원·손절 gap·청산 경계·캔들 미래 참조 방지·지연 주문·리스크 중단을 검증한다. 작은 수작업 예제로 계좌 원장 잔고를 대조한다. 결과는 코드 버전, 데이터 해시, 설정, 난수 seed로 재현 가능하게 남긴다.
