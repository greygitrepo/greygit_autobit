## A1 — 4h 추세 필터 + 1h 돈치안 돌파 + ATR 추적 손절 (`a1_breakout:A1Breakout`)

| 단계 | 내용 |
|---|---|
| 출처 | C03 (Bullish 2025 상위 3팀 모두 '방향성' 라벨, 3위 'CTA/모멘텀'; 공식 수상 페이지, 규칙 미공개) / C02 (주최측 체결 원자료에서 연구자가 산출: 승률 31%, 손익비 약 2.5, 우측 꼬리 의존, BTC·ETH 90%) |
| 원칙 | P3 방향성·추세(명시 1 + 해석 1 / 9), P4 우측 꼬리 의존(1/9), P5 메이저 집중(2/9), P6 비용 잠식(1/9, 제약 조건). P3·P4는 같은 현상의 두 면이므로 독립 근거 2개로 세지 않는다. |
| 정량 가설 (자체 가정) | 확정 4h EMA50/EMA200 방향과 같은 쪽의 1h 20봉 돌파만 따르면, 비용·펀딩 차감 후 기대값이 양(+)이고 승률 30~45%, 손익비 ≥ 2, 상위 10% 거래가 총손익의 ≥100%를 설명한다. |
| 코드 규칙 | ① 추세: 1h 봉으로 4h 봉을 재구성, 1h 행 t의 종가 시점까지 **닫힌** 4h 봉만 사용. EMA50 > EMA200 → 롱만, < → 숏만 (자체 가정: 50/200) ② 진입: 1h 종가 > 직전 20봉 최고가 → 롱, < 직전 20봉 최저가 → 숏. 엔진이 다음 1m 봉에서 체결 (자체 가정: 20) ③ 초기 손절: 종가 ∓ 2.0×ATR14(1h) (자체 가정) ④ 추적: 진입 후 최고(최저) 종가 ∓ 3.0×ATR14, 손절은 조이는 방향으로만 이동 (자체 가정) ⑤ 청산: 손절 접촉(봉 고가/저가로 내부 판정, 실제 체결은 엔진 1m 손절 주문) 또는 4h 필터 반전 → target 0 ⑥ 크기: 공통 엔진(0.25%×1만 / 손절거리, 총 3배 상한). size_mult 미사용 ⑦ 심볼당 1포지션, 피라미딩 없음 |
| 검증 지표 | 비용 차감 순수익률, MDD, 수익/MDD, 일간 Sharpe·Sortino, 거래 수, 승률, 손익비, PF, 상위 10% 거래 기여율, 수수료+펀딩/총손익(목표 <30%), BTC·ETH 개별, 인접 파라미터 안정성(n 10~40, 배수 1.5~4), 비용 스트레스(spread×3, impact×3, latency 1000ms), 현금(0%) 대비 |

## A2 — 시계열 모멘텀 (사전 선언, 테스트 전 기재) (`a2_tsmom:A2TSMom`)

근거: C03 3위 'CTA/모멘텀' 라벨. 돌파형(A1)과 같은 원칙(P3)의 다른 구현으로, A1이 1h 잡음에 취약할 경우의
대안. 신규 원칙이 아니므로 독립 근거로 세지 않는다. 모든 수치 자체 가정.

| 단계 | 내용 |
|---|---|
| 정량 가설 | 4h 봉 기준 직전 30일(180봉) 수익률 부호 방향으로 보유하면 비용 차감 후 기대값이 양(+)이고 A1보다 거래 수·비용 비중이 낮다. |
| 코드 규칙 | ① 신호: sign(close_t / close_{t−L} − 1), L=180(4h) ② 진입: 신호 방향, 무포지션일 때 ③ 손절: 종가 ∓ 3.0×ATR14(4h) 초기, 이후 최고(최저) 종가 ∓ 3.0×ATR 추적(조이기만) ④ 청산: 손절 접촉 또는 신호 반전(반전 시 반대 방향 진입) ⑤ 손절 후 재진입: 같은 신호가 유지되면 직전 거래의 최고(최저) 종가를 넘어설 때만 ⑥ 크기: 공통 엔진 |
| 검증 지표 | A1과 동일 + A1 대비 거래 수·비용 비중 |

## 실험 계획 (결과 보기 전 기재)

- 튜닝은 train(2021-10-09~2024-09-30)에서만. 인접 파라미터: n ∈ {10, 20, 30, 40}, trail_mult ∈ {2, 3, 4}, init_mult ∈ {1.5, 2, 3}.
- validation(2024-10-01~2025-09-30)에서는 train 후 아래 '사전 선언 변형'(≤5개) 중에서만 고른다. test는 사용하지 않는다.
- 총 등록 실험 약 30회 이하. 실패 포함 전부 `experiments/registry.csv`에 등록.
